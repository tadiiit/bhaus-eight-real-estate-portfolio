# Bhaus Eight — Independent Redesign Concept

A responsive React + Vite portfolio demonstrating a proposed luxury real-estate website redesign concept for Bhaus Eight. This is an independent portfolio concept only.

## Important boundaries

- This is **not** a completed or commissioned client project. The site does not claim Bhaus Eight hired the developer or approved this concept.
- Nothing is changed or published to the live Bhaus Eight website.
- Property cards, descriptions, and community content in the concept homepage are illustrative, not verified listings or client statements. No prices, addresses, testimonials, analytics, or results are fabricated.
- Photos are loaded from Unsplash image URLs as illustrative imagery. Verify license/usage suitability and replace with properly licensed/authorized assets before commercial deployment.
- `hello@example.com` is a placeholder. Replace it with a real contact address.
- No repository or demo URLs are invented for the separate AI Lead Qualification Agent project.
- This portfolio describes an audit-first SEO plan, not completed SEO work or guaranteed rankings.

## Requirements

- Node.js 18+ (Node 20 LTS recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local development URL, typically `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

Deploy the generated `dist/` directory to a static host that supports Vite output. Configure the correct base path if deploying beneath a subpath.

## Interactive features

- Mobile navigation in the main portfolio header and the proposed homepage mockup.
- Property concept filter and save-state toggle (local UI only).
- Clickable community cards that reveal a proposed page-content outline.
- Expandable sitemap groups.
- Six-stage implementation process selector with previous/next controls.
- Contact email copy control with feedback state.
- Responsive layouts and reduced-motion CSS support.

## Proposed homepage content

The embedded homepage concept includes a header, coastal hero, illustrative property cards, South Bay community guides, buyer/seller resource cards, editorial/journal section, inquiry CTA, and footer.

## Before publishing

1. Replace the placeholder email.
2. Review all image licenses and optimize/self-host assets as appropriate.
3. Add verified repository/demo URLs for real projects.
4. Audit the client's current website, platform setup, content, analytics, and SEO before stating any findings.

## Scope and platform note

The concept is implemented in React to demonstrate UI/UX and frontend capabilities. A real client implementation would be scoped against the existing Squarespace setup and may use native Squarespace components, supported custom code, or another agreed approach depending on the audit.
